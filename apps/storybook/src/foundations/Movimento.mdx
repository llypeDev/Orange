# Movimento

O Orange se move como uma ferramenta: **rápido, funcional e geométrico**. Botões afundam 1px, cartões sobem
4px, setas deslizam 4px, sublinhados crescem da esquerda e o conteúdo entra 24px de baixo ao rolar. Saídas são
mais curtas que entradas e tudo é zerado com `prefers-reduced-motion`.

| Padrão | Como |
| --- | --- |
| Entrada/saída de sobreposições | `usePresence(open)` + `data-state` + `or-motion-pop` / `or-motion-drop` / `or-motion-fade` |
| Pressionar | `:active` → `translateY(1px) scale(0.985)` em `--or-duration-press` (`or-press`) |
| Elevar | `translateY(var(--or-distance-lift))` + `box-shadow: var(--or-shadow-lift)` + barra de acento que desce pela borda esquerda (`scaleY` 0 → 1) + ponte de 12px contra tremor (`or-lift`) |
| Seta que empurra | `or-nudge` + `or-nudge__icon` (4px) |
| Sublinhado | `or-underline` (cresce da esquerda via `background-size`) |
| Expandir/recolher | `or-collapse` + `data-state` (`grid-template-rows` 0fr → 1fr) |
| Status ao vivo | `or-pulse` + `--_pulse-color` |
| Erro | `or-shake`, uma vez |
| Progresso temporizado | `or-fill-x` (`scaleX` 0 → 1) |
| Revelação no scroll | componente `Reveal` / hook `useInView` |
| Números | `useCountUp(valor)` |
| Cabeçalho | `useScrollDirection()` |

## Movimento reduzido

Com `prefers-reduced-motion: reduce`, todas as durações, distâncias e o stagger viram zero, o `base.css`
encurta qualquer animação restante, o `Reveal` mostra tudo de imediato, `or-pulse` para e `useCountUp`
devolve o valor final. Para lógica em JavaScript, use `useReducedMotion()`.

## Regras

- Anime só `transform`, `opacity`, cores, bordas e `box-shadow` — exceção: `grid-template-rows`.
- Nunca escreva `ms` ou `cubic-bezier` soltos: use os tokens, que zeram sozinhos.
- Hover e foco visível sempre com a mesma resposta; movimento nunca é a única pista de estado.
- Animações infinitas só para status e carregamento.
